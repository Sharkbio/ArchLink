# Versioned Source Data

This directory contains the combined quantitative Source Data workbook used by
the reproducible figure entry points, its editor-facing guides and the central
panel provenance map.

- Workbook: `Source_Data.xlsx`
- Panel map: `Figure_Panel_Data_Source_Map_v3.csv`
- Workbook SHA-256: `6ae85c320a615795cae0209eb089e50c5330a52fa4ad26e967ea7f73f217036d`
- Submission package date: 2026-08-29

The workbook covers quantitative panels for Figures 2-6. Conceptual diagrams,
tree styling, molecular rendering and final multi-panel assembly are documented
in the workbook's `Panel_Map` and `NonTabular_Notes` sheets instead of being
represented as artificial numeric tables.
